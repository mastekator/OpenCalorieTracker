2W · Вес: все выводы и пустые случаи

План — темп из цели профиля. По плану — 75–125% плана; медленнее — меньше 75% в ту же сторону; быстрее — больше 125% (больше 1% веса в неделю — предупреждение); против плана — тренд в обратную сторону больше 0,1 кг/нед. Цель «держать вес» — держится, если тренд в пределах ±0,5 кг за месяц. Тренд — с 3 взвешиваний на отрезке от 7 дней.

2D · Блюда: пустые и частные случаи

Одинаковые блюда — по названию без учёта регистра и пробелов по краям. «Частые» — по числу раз, при равенстве — по сумме ккал. «Любимое» — первое из частых, если было 3 раза и больше. «Больше всего ккал» — до 3 блюд из встречавшихся 2+ раз. В картинку и текст «Поделиться» уходят 3 частых блюда.
