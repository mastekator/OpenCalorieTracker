Social preview · 3 variants

The image GitHub shows when the repository link is shared in a chat or a post. 1280×640, in the README “Photo first” look with the Macro peas logo. Text is large, no screenshots. Switch the theme in the bar above to compare a light and a dark ground: one image is uploaded, so pick a variant and a ground. Under each variant: how it looks in a link card at about 400 and 240 px wide.

A · Banner

The README banner, stretched to the card. Same eyebrow, name and tagline, the plate cluster on the right. The repo page and the shared link look like one thing.

B · Snap, then numbers recommended

Leads with what the app does, not its name: a big headline, one plate turning into calories and macros. The name and logo sit small at the bottom, the way the link title already repeats them.

C · Logo first

A large Macro peas mark and the name in the middle, one line under it, food around the edges. Quietest of the three; reads best at the smallest size.

Notes

  • Recommended ground: light (theme bar → Light). A link card in a dark chat gets a light block that stands out; the dark one blends into it.
  • Why B: in the 240 px card only the headline is still readable, and B’s headline says what the app does; A and C shrink to the name, which the link title already shows. Smallest text is 30 px at 1280 wide (about 9 px in a 400 px card); the headline is 80 px.
  • Safe zone: nothing important within 60 px of the edges, some chats crop the card to a square-ish frame.
  • The chosen one is exported as docs/assets/social-preview.png (PNG, under 1 MB) and replaces the current file in a PR; the owner uploads it in the repository settings.
