Launch animation: the pod opens

The closed pod squeezes, opens on its hinge and lets out three peas — protein, fat, carbs. One second in total, it plays while the app loads and never makes you wait: if Today is ready earlier, the animation is cut. With “Reduce motion” on, the final logo is shown at once.

Spec for development

Timing

  • Whole sequence: --duration-splash = 1000 ms; steps are shares of it.
  • 0–15 % pod squeeze; 15–50 % lid opens (rotate 17° → 0° on the left tip, opacity 1 → .5).
  • 35–75 % peas pop 0 → 1 in the order protein, fat, carbs, 8 % apart, --ease-spring.
  • 65–95 % wordmark fades in and rises 8 px. Then cross-fade to Today, --duration-base.

Where it plays

  • iOS shows the static launch image first; it cannot move. That image becomes the first frame — the closed pod — so the animation continues it without a jump.
  • Only on a cold start. Returning from the background shows the app straight away.
  • Never delays the app: if data is ready before the end, skip to Today.
  • Reduce motion: --duration-splash is 0 ms, the final logo shows without movement.

Build

  • Inline SVG with the mark split into pod, lid and three peas; CSS keyframes only, no animation library.
  • Transforms and opacity only, so it stays smooth on older iPhones.
  • Colours come from the logo tokens for the light and dark grounds.
